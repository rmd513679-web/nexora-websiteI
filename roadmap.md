# NEXORA Roadmap — Working Draft

1. Align the whitepaper, tokenomics, code constants, and test expectations for the 30M cap and proposed 2M founder / just-under-20M mining / 8M reserve plan.
2. Add automated CI tests, including emission-schedule, halving-boundary, malformed-chain, and supply-cap tests.
3. Specify the transaction model, fees, and replay protection.
4. Implement reviewed digital signatures and safe wallet/key handling.
5. Add persistent storage and specify the peer-to-peer node protocol.
6. Run a no-real-value testnet; test conflicting blocks, reorganizations, and network failures.
7. Complete independent security review and fix critical findings.
8. Consider mainnet only after protocol freeze, audits, documentation, and operational readiness.

Roadmap items are goals, not completed features or guarantees.
