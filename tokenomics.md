# NEXORA Tokenomics — Draft

## Fixed planning target
- Planned maximum supply: 30,000,000 NEXORA
- Consensus concept: Proof of Work
- Initial allocation: undecided
- Block reward: undecided
- Halving interval: undecided
- Smallest unit: undecided
- Transaction fees: undecided

## Issuance requirement
Before launch, define a deterministic issuance function and prove through tests that cumulative
coin creation cannot exceed 30,000,000 NEXORA. Specify integer arithmetic in the smallest unit;
do not use floating-point arithmetic for consensus amounts. Define what happens when the remaining
supply is smaller than a full reward.

## Transparency commitments proposed
- Publish the exact reward formula and genesis allocation before launch.
- Make consensus rules reproducible from source and test vectors.
- Do not advertise exchange listings, returns, or mining income as guaranteed.
- Do not accept real funds while the software is experimental.
