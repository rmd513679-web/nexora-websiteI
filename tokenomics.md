# NEXORA Tokenomics — Working Draft

NEXORA is an experimental project. These parameters are proposals and are not a live asset.

- Maximum supply cap: 30,000,000 NXR.
- Smallest unit: 0.00000001 NXR (100,000,000 units per NXR).
- Initial block reward: 50 NXR.
- Draft halving interval: 200,000 blocks.
- Proposed lifetime mining emission: just under 20,000,000 NXR because rewards are integer-rounded in smallest units.
- Proposed founder allocation: 2,000,000 NXR (not implemented).
- Proposed ecosystem/reserve allocation: 8,000,000 NXR (not implemented).

The current prototype only accounts for mining rewards. It does not create founder or reserve balances, implement transfers, or lock/vest allocations. These allocations and the halving interval must be reviewed and finalized before any public network launch. No exchange listing, price, profit, or liquidity is guaranteed.
